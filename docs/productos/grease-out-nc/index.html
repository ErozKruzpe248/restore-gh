GREASE OUT NC

Desengrasante neutro para pisos epóxicos.

Consultar ficha técnicaCotizar

Qué es y para qué sirve

Desengrasante base agua para remoción de aceites y grasas industriales y automotrices. Su aplicación principal en el catálogo es la limpieza de pisos epóxicos.

Características y beneficios

  • Desengrase de pisos epóxicos.
  • Formulación base agua para retirar aceites y grasas.

¿Cuándo elegirlo?

Considera NC cuando la necesidad principal es desengrasar pisos epóxicos.

Aplicaciones

  • Pisos epóxicos
  • Paredes, equipos y maquinaria
