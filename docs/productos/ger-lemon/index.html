GER LEMON

Limpieza de superficies lavables con agua.

Consultar ficha técnicaCotizar

Qué es y para qué sirve

Limpiador para pisos, paredes, ventanas y otras superficies que pueden lavarse con agua. Consulta la documentación original para las indicaciones específicas de uso.

Características y beneficios

  • Limpieza de superficies que pueden lavarse con agua.
  • Aplicaciones en pisos, paredes y ventanas.

¿Cuándo elegirlo?

Considera GER LEMON para limpieza de pisos, paredes o ventanas lavables con agua.

Aplicaciones

  • Pisos y paredes
  • Ventanas y superficies lavables
