HAND CLEAN

Jabón líquido para limpieza de manos.

Consultar ficha técnicaCotizar

Qué es y para qué sirve

Jabón líquido concentrado para la limpieza de manos con grasa, carbón, algunos tipos de tinta y suciedad. La literatura describe aplicaciones en talleres, restaurantes y fábricas, y su uso con dispensadores para líquidos.

Características y beneficios

  • Presentación líquida para dispensadores.
  • Limpieza de suciedad en manos en distintos entornos de trabajo.

¿Cuándo elegirlo?

Elige HAND CLEAN cuando buscas un jabón líquido para limpieza de manos.

Aplicaciones

  • Limpieza de manos
  • Talleres, restaurantes y fábricas
  • Dispensadores para jabón líquido
