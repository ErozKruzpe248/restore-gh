Privacidad

Tu solicitud, bajo tu control.

Este sitio prepara mensajes de contacto para que puedas enviarlos desde tu correo.

Formulario de contacto

Los datos que introduces se utilizan en tu navegador para preparar el texto de una solicitud. El sitio no guarda esos datos en una base de datos ni envía automáticamente el formulario.

Envío por correo

Al seleccionar “Abrir correo”, se abrirá tu aplicación de correo con un mensaje preparado. El envío se realiza únicamente cuando tú lo confirmas en esa aplicación. La gestión del correo corresponde a tu proveedor de correo y al destinatario.

Documentos externos

Los enlaces de documentación abren archivos publicados en restoregh.com, sujetos a las condiciones de ese sitio. Las tipografías se cargan desde Google Fonts.

Contacto

Para consultas relacionadas con los datos enviados al equipo, escribe a contacto@restoregh.com.
